Two highly requested features: Uninstaller scan modes and automatic update checker

🛡️ Uninstaller Scan Modes

Choose how aggressive the Uninstaller should be when finding leftover files:

  • Safe Mode — Only finds high-confidence files (matching by Bundle ID, exact app name, or receipts). Completely disables Spotlight (mdfind) and fuzzy matching. Minimizes risk of accidentally affecting shared files.
  • Balanced Mode (Default) — Performs a full deep scan, including Spotlight and extended paths, to find all possible leftovers. Recommended for thorough cleanups.

Switch between modes anytime in Settings → Uninstaller.

🔄 Smart Update Checker
  • Automatically checks for new versions on startup directly via GitHub Releases.
  • Gentle native notification in the About window and Settings when an update is available.
  • Privacy First — no background daemons, no persistent tracking, and no extra dependencies.
  • Manual check available in Settings → General tab.

How It Works

Built for Apple Silicon with full parallelism

1

Scan

Stack-based iterator batches work and deduplicates inodes. Size calculations are cached to avoid redundant work. All categories run in parallel across all available cores for maximum speed.

2

Review

Risk badges (Safe / Moderate / Dangerous / Protected) appear after scan. You pick what to delete, then confirm. Dev-related tasks show a purple "DEV" badge.

3

Trash

Everything goes to Trash via trashItem(at:) — always recoverable. SafetyManager blocks access to /System, /usr, /bin, ~/.ssh, and other critical paths.

4

Verify

Post-cleanup confirmation with reclaimable space summary. Snapshots stored for rollback. Full audit log via OSLog — open Console.app and filter by com.alextkdev.macos-cleaner.
