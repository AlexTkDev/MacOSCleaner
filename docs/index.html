Features

Everything you need to keep your Mac clean

📊

Dashboard

Disk usage chart, system info (model, CPU, RAM, macOS version), cleanup history & stats — with a dynamic Radar Chart displaying size distributions.

🔍

Smart Cleanup

Scans 54 categories with 450+ built-in paths. App caches, browsers, package managers, dev tools, Docker, system caches, user logs, orphaned files, and custom developer directories (.dart_tool, Maven, Go module cache).

🧠

Apple Intelligence

Native, local AI explanations powered by FoundationModels. Explains files, caches, running processes, and startup agents fully offline on supported Apple Silicon Macs.

📁

Disk Analyzer

Scan any folder hierarchically, browse items sorted by size, view categorized breakdowns (Video, Audio, Photos, Apps, Docs, Archives), and move large items to Trash.

🗑

App Uninstaller

Drag and drop `.app` bundles to scan up to 5 levels deep using 30 evidence types. Safe & Balanced scan modes, confidence tiers, and tailored rules for popular apps.

⚙

Process Manager

List running processes in Flat or Grouped views. Sort by CPU/Memory, bulk terminate, and use custom Whitelists and Blacklists to protect or block specific apps.

🚀

Startup Services

Scan LaunchAgents and LaunchDaemons (user and system). Categorizes into User, Third-party, and System services. Toggle or stop services, and set custom System Vendors.

🔄

Smart Updates

Automatic lightweight update check on startup via GitHub Releases. No background daemons, no persistent tracking, no extra dependencies.

🔒

Safety First

Everything goes to Trash via trashItem(at:) — always recoverable. SIP and system paths blocked. Permanent deletion is opt-in.

🌍

Fully Localized

English, Русский, Українська, Español. All UI, errors, logs, and system info translated dynamically. Dates and byte counts format correctly.

How It Works

Built for Apple Silicon with full parallelism

1

Scan

Stack-based iterator batches work and deduplicates inodes. Size calculations are cached to avoid redundant work. All categories run in parallel across all available cores for maximum speed.

2

Review

Risk badges (Safe / Moderate / Dangerous / Protected) appear after scan. You pick what to delete, then confirm. Dev-related tasks show a purple "DEV" badge.

3

Trash

Everything goes to Trash via trashItem(at:) — always recoverable. SafetyManager blocks access to /System, /usr, /bin, ~/.ssh, and other critical paths.

4

Verify

Post-cleanup confirmation with reclaimable space summary. Snapshots stored for rollback. Full audit log via OSLog — open Console.app and filter by com.alextkdev.macos-cleaner.
