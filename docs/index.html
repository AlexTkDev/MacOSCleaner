01 · Features

Native SwiftUI with On-Device Apple Intelligence

Everything runs locally. No telemetry, no analytics, zero cloud transmission.

  • On-Device Apple Intelligence

    Native local AI explanations powered by Apple FoundationModels. Explains files, caches, running processes, and startup agents offline with zero latency or cloud transmission. Tap the sparkles icon anywhere to ask.

  • Siri & Shortcuts Automation

    Native AppIntents integration for voice control and automated Shortcuts workflows. Trigger "Quick Clean", "Scan Storage", or "Uninstall App" with Siri or custom macOS Shortcuts — zero background daemons or battery drain.

  • Smart Cleanup (1,770 Paths)

    54 categories, 1,770 path definitions — app caches, browsers, package managers, Xcode, Docker, orphaned leftovers, large installers. Parallel scan across all cores. Risk badges after scan; you choose what to remove.

  • Forensic App Uninstaller

    Drag & drop any .app. Scans up to 5 levels with 30 evidence types (Bundle ID, Team ID, Spotlight, plist, Launch Services). Safe or Balanced mode. Confidence tiers: guaranteed → ignore.

  • Duplicate File Finder

    Multi-stage cryptographic engine (file size → 4 KB hash → full SHA-256) running parallel on Swift Actors. Safely detects 100% exact duplicates and protects master original files.

  • Disk Space Analyzer

    Scan any folder, browse by size, filter by Video / Audio / Photos / Apps / Documents / Archives. Reveal in Finder or move to Trash. Keeps scanning in the background.

  • Process Manager

    Flat or Grouped views. Sort by CPU, Memory, Name, or Threads. Whitelist critical apps; blacklist noisy ones for quick termination. System processes stay protected.

  • Startup Services

    LaunchAgents and LaunchDaemons from ~/Library and /Library. Grouped into User, Third-party, and System. Load, unload, or stop — with admin prompt when needed.

  • Safety & Privacy First

    Uninstaller and Disk Analyzer move items to Trash via trashItem(at:). Smart Cleanup removes selected caches only after you confirm. SafetyManager blocks /System, /usr, ~/.ssh, and other critical paths.

  • 10 Languages & Liquid Glass

    English, Deutsch, 日本語, Français, 简体中文, Italiano, Português, Español, Русский, Українська — UI and error localizations. Adaptive Liquid Glass UI for macOS 27+.

06 · How it works

Scan → Review → Clean → Verify

Swift 6 · SwiftUI · XcodeGen · OSLog — parallel on Apple Silicon

  1. 01

    Scan

    Stack-based iterator batches work and deduplicates inodes. Size cache avoids redundant work. Categories run concurrently across cores.

  2. 02

    Review

    Risk badges (Safe / Moderate / Dangerous / Protected). DEV badge on developer paths. Optional local AI explanations before you decide.

  3. 03

    Clean

    Uninstaller and Disk Analyzer → Trash. Smart Cleanup removes selected items after confirmation. Critical paths stay blocked.

  4. 04

    Verify

    Post-uninstall re-scan and snapshots for rollback. Logs in Console.app — filter subsystem input.MacOSCleaner.
