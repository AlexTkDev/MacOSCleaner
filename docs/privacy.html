1. macOS Application Privacy (Zero Telemetry)

The MacOSCleaner desktop application runs locally on your Mac. It contains no analytics SDKs, crash-reporting telemetry, advertising identifiers, user accounts, or background daemons. File checksums, TCC/socket inspections, and Apple FoundationModels explanations execute strictly on-device without cloud relays.

The only optional network connection queries the public GitHub Releases endpoint (api.github.com/repos/AlexTkDev/MacOSCleaner/releases/latest) to check whether a newer DMG version is available. You can disable automatic update checks in Settings at any time.
