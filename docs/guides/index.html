Developer Cleanup Guides

Safe, verifiable ways to reclaim macOS disk space without breaking Xcode, Docker, or active projects

Most macOS storage bloat for developers comes from predictable places: Xcode DerivedData and simulator runtimes, Docker Desktop sparse disks, and package manager caches lumped under System Data. Pick a guide below.

How to clean Xcode caches safely on Mac

What lives inside DerivedData, Archives, iOS DeviceSupport, CoreSimulator runtimes, and SwiftPM caches — and what is safe to move to Trash.

Clean Docker disk space on Mac (never delete Docker.raw)

Why Finder reports misleading logical sizes for sparse VM disks, how to measure with docker system df, and how to prune images and build cache safely.

macOS System Data is too large — a developer reclaim order

Step-by-step order to audit APFS local snapshots, Homebrew, Cargo, npm/pnpm, CocoaPods, and build artifacts without touching system files.
