# Безопасный выпуск macOS Cleaner 2.1.0

## 1. Немедленный safety gate
- Считать релиз заблокированным до закрытия всех P0/P1; не запускать текущий полный test suite до изоляции файловой системы.
- В [CleanupEngine.swift](MacOSCleaner/Domains/Cleanup/CleanupEngine.swift), [RunScheduledCleanupIntent.swift](MacOSCleaner/Features/AppIntents/RunScheduledCleanupIntent.swift) и defaults временно убрать из автоматического выполнения `.orphanedRemnants`, `.orphanedFiles`, `.oldBackups`, `.launchAgents`, `.launchDaemons`, `.privilegedHelpers`, user-content/model roots.
- Сохранить настройку `bypassTrashOnUninstall`: если она включена, удалять только явно выбранные и повторно валидированные targets напрямую; если выключена — перемещать их в Корзину. Для обоих режимов одинаково применять ownership, shared/user-content, symlink и cancellation guards. `emptyTrashImmediately` не должен очищать чужие элементы Корзины.

## 2. Изолированный filesystem-контекст
- Ввести небольшой `FileSystemContext` с `homeDirectory`, разрешёнными scan roots и `FileManager`; передавать его в [CleanupEngine.swift](MacOSCleaner/Domains/Cleanup/CleanupEngine.swift), [FileCleanupActor.swift](MacOSCleaner/Infrastructure/FileCleanupActor.swift), [CandidateCollector.swift](MacOSCleaner/Features/Uninstaller/CandidateCollector.swift), [AppResidualsOrphanEngine.swift](MacOSCleaner/Features/Uninstaller/AppResidualsOrphanEngine.swift) и [DeveloperComponentsDetector.swift](MacOSCleaner/Features/Uninstaller/DeveloperComponentsDetector.swift).
- В тестах использовать только UUID temp root. Добавить fail-closed guard: destructive test operation вне test root немедленно падает до filesystem mutation.
- Исправить [SafetyManager.swift](MacOSCleaner/Infrastructure/SafetyManager.swift): custom exceptions не перекрывают `/System`, `/Applications`, `/Users/Shared`, `/opt`, `/Library` и sensitive roots; проверять каждый symlink-компонент через resource values/lstat, не обходить symlink directories, leaf symlink перемещать как ссылку.

## 3. Безопасная схема registry и codegen
- Расширить `PathPurpose` в [engine_paths.json](MacOSCleaner/Resources/engine_paths.json) и [generate_cleanup_paths.swift](scripts/generate_cleanup_paths.swift) классом `user_content`/`informational`: никогда не auto-select и не удалять unattended.
- Запретить валидатором bare home tokens и `app_data` под Desktop/Documents/Movies/Music/Pictures/Downloads/cloud roots; разрешать такие пути только как `user_content`.
- Разделить Microsoft Word/Excel/PowerPoint/Outlook/Teams на отдельные bundle entries; `UBF8T346G9.Office`, OneDrive suite, Adobe/Unity vendor roots, updater и licensing paths пометить `shared`.
- Убрать broad app-data globs (`com.microsoft.*`) и cross-app ownership; проверить все cross-entry path collisions.
- Переклассифицировать Ollama/HuggingFace/Torch/Whisper models и `~/.pub-cache` tool state из обычного cache: models/user tools — отдельный opt-in/informational класс; Dart cache — только подтверждённые regenerable подкаталоги.
- Chromium `Service Worker` сузить до `CacheStorage`/`ScriptCache`; registration/state/database оставить `app_data`.
- Codegen должен сохранять `purpose`, `system/requiresAdmin`, glob и ownership до runtime; `--check` после успеха создаёт declared stamp, а [project.yml](MacOSCleaner/project.yml) перечисляет JSON, validator и generator как inputs.

## 4. Единый runtime cleanup
- Все registry-backed категории (`appCaches`, `messagingMedia`, `languageCaches`, `systemCaches`, browser/IDE/dotfile) маршрутизировать через `resolvedEmbeddedPaths`/единый executor; удалить дублирующие hardcoded списки из [CleanupEngine.swift](MacOSCleaner/Domains/Cleanup/CleanupEngine.swift).
- Явно исключить `~/Library/Messages/Attachments`, GoogleSoftwareUpdate/GoogleUpdater/Keystone и любые `shared`, `app_data`, `user_content`, admin paths из обычной cleanup.
- Не очищать корни LaunchAgents/LaunchDaemons/PrivilegedHelperTools целиком: только конкретные доказанные app-owned файлы.
- `.oldBackups` заменить review-only поиском с возрастом и явным выбором; `~/Backups` никогда не очищать wholesale.
- AI models, global package stores, Android SDK/CoreSimulator/Gradle/DerivedData оставить невыбранными и вынести из uninstall в отдельное подтверждение.
- Возвращать structured result `removed/skipped/failed`; partial failures не маркировать success.

## 5. Uninstaller ownership и orphan engine
- В [CandidateCollector.swift](MacOSCleaner/Features/Uninstaller/CandidateCollector.swift) убрать suite-wide vendor roots, substring scan Documents/Desktop и безусловный `.pvm/.vmx`; точные registry paths и entitlements/receipts считать сильными уликами, shared/user-content показывать только info/unselected.
- Другие app copies с тем же bundle ID и другие Homebrew versions показывать отдельно, не выбирать; основной delete target всегда только `identity.bundleURL`.
- Orphan detection в [AppResidualsOrphanEngine.swift](MacOSCleaner/Features/Uninstaller/AppResidualsOrphanEngine.swift) учитывать LaunchServices, все application locations, package receipts, team ID и application groups. Требовать минимум две независимые ownership-улики; неоднозначные результаты только manual review, никогда scheduled cleanup.
- Добавить `Task.checkCancellation()` перед обходами, probes и каждой mutation; `CancellationError` не подавлять.
- Для производительности построить один bounded filesystem index на scan session и матчить все identities по нему вместо полного обхода Library для каждого приложения.

## 6. Перестройка тестов без риска
- Сначала исправить [CleanupIntegrationTests.swift](MacOSCleaner/MacOSCleanerTests/CleanupIntegrationTests.swift), [CandidateCollectorTests.swift](MacOSCleaner/MacOSCleanerTests/CandidateCollectorTests.swift) и [RegistryPathsTests.swift](MacOSCleaner/MacOSCleanerTests/RegistryPathsTests): никакого `NSHomeDirectory()`, реальных Chrome/Group Containers/Trash и sleep-based cancellation.
- Добавить end-to-end regressions на сохранение Messages attachments, Google updater/Keystone, browser credentials/state, backups, AI models, Dart global tools, user documents/cloud roots, sibling Office/Adobe apps, VM disks/source dirs, active app groups и allowed-root symlinks.
- Superset test проверяет path ownership и policy для каждого bundle ID/prefix, не global union; sourceHash сравнивается с SHA-256 SoT.
- Shared/admin tests создают реальные temp fixtures и отдельно проверяют `candidates`, `catalogPaths`, `sharedPaths`, rejected admin.
- Cancellation проверять deterministic barrier/fake actor: после cancel ни одной следующей mutation.
- Glob tests: bounded fan-out, permission errors, symlink skipping, cancellation и лимит matches; добавить performance budgets для registry lookup и scan session.
- UIMetadata tests проверяют ресурс app bundle, exact key и longest-prefix match без fallback к source tree.

## 7. CI и release gates
- В [.github/workflows/build.yml](.github/workflows/build.yml) исправить release branch trigger и добавить последовательные gates: validator, codegen `--check`, XcodeGen drift check, isolated `xcodebuild test`, Release build.
- Первый безопасный прогон: targeted non-destructive tests; затем isolated full suite два раза. Подтвердить отсутствие обращений к реальному home через operation spy/log assertion.
- Проверить bundle: `ui_metadata.json` присутствует, `engine_paths.json` отсутствует; generated hash совпадает.
- Ручная матрица на disposable macOS account/VM: Chrome cleanup сохраняет profiles; Messages attachments сохраняются; Word не затрагивает Excel/OneDrive; uninstall не выбирает user content/VM/models; shared updater остаётся; cancel останавливает mutations; partial errors видны.
- Только после нулевых P0/P1, зелёного CI и performance budget обновить статусы в [implementation_plan.md](implementation_plan.md) и [plan.md](plan.md), собрать и проверить release artifact 2.1.0.
